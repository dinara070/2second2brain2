# 🧠 Другий мозок

Streamlit-сервіс: підключає пошту (IMAP), календар (.ics) і нотатки (.md/.txt) та відповідає на питання з цитуванням джерел.

## Запуск
```bash
python -m venv .venv && source .venv/bin/activate   # Python 3.11+
pip install -r requirements.txt
streamlit run app.py
```
Локальна LLM: `ollama pull llama3.1`. Хмарна: `export ANTHROPIC_API_KEY=...`.

## Приватність
- Сховище на диску зашифроване (scrypt → Fernet); індекс розшифровується лише в пам'яті.
- Пошта відкривається `readonly`, пароль IMAP не зберігається.
- Ембедінги рахуються локально (multilingual-e5-small).
- Режим Ollama: жодні дані не залишають машину.
- Режим Claude: надсилаються лише топ-фрагменти, email/телефони/IBAN/картки замінюються токенами й повертаються локально.
- Листи вважаються недовіреними даними (захист від prompt injection у промпті).

## Якість пошуку
BM25 (FTS5, префіксний «стемінг» укр. закінчень) + семантичний пошук → злиття RRF; фрагменти мають заголовок
`[джерело] тема (дата)`; фільтр за датою з питання («у березні», «минулого тижня»); не більше 2 фрагментів з документа.

## Обмеження
Повторювані події календаря не розгортаються; вкладення не індексуються; OAuth не реалізовано (пароль застосунку).
